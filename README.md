# RMGAF

检查并修复 RPG Maker **MV / MZ** 游戏资源路径的大小写差异。以 `data/*.json` 为主直接扫描；默认不执行游戏 JavaScript。对于可信游戏，可显式授权执行其数据库加载器，在内存中解码自定义格式后继续检查。

```console
rmgaf /path/to/game --check
rmgaf /path/to/game
```

传入 **`index.html` 所在目录**：MV 部署包通常是 `www`，MZ 通常与 `nw.exe` 同级

## 安装与运行

```sh
npx @q78kg/rmgaf /path/to/game
```

## 使用

| 参数               | 行为                                                         |
| ------------------ | ------------------------------------------------------------ |
| `rmgaf <dir>`      | 检查并执行无歧义的大小写重命名                               |
| `--check`          | 只检查，不执行资源重命名；与可信代码选项组合时仍会执行加载器 |
| `--trust`          | 明确授权执行可信游戏的数据库加载器，解码不可读 JSON          |
| `-v` / `--verbose` | 显示全部差异、问题及引用来源                                 |
| `--no-color`       | 关闭颜色和动画；也支持 `NO_COLOR` 环境变量                   |
| `--version`        | 显示版本                                                     |
| `--help`           | 查看用法                                                     |

交互终端显示扫描动画、当前文件、资源统计、重命名差异与耗时；重定向到文件或管道时不输出动画与 ANSI 颜色。默认限制差异展示数量，大量问题可用 `--verbose` 完整输出。

`rename 旧路径 → 新路径` 是扫描生成的改名计划，末尾的 `Repaired N names` 才表示实际执行数量。若出现 `error`、`conflict` 或 `unsafe`，会显示 `Blocked … no files renamed`，整次修复不写入；`--trust` 仅授权执行加载器，不会绕过这些错误。

```sh
rmgaf ./www --check --verbose > report.txt
```

退出码：`0` 表示扫描完成且没有阻塞型错误；`1` 表示存在待修复大小写、冲突、无法完整读取的数据或其他阻塞问题；真正缺失的资源只报告为 `missing`，不使命令失败；`2` 表示命令参数、目录或 I/O 错误；中断为 `130`。`--check` 发现大小写问题时返回 `1`，便于脚本/CI 使用。

## 检查范围

**JSON 优先：** 枚举 `data` 下的 JSON，按 MV/MZ 标准字段和事件指令解析资源名；不会把剧情文本中的任意字符串猜成文件名。

- 角色行走图、头像、战斗图；敌人图及横版/正面战斗目录。
- 系统标题、战斗背景、载具、BGM/ME/SE；MZ 字体。
- 地图、事件页、公共事件、战斗事件、移动路线中的图片、音频、视频。
- 图块、远景、MV 动画图片/音效、MZ `.efkefc` 动画文件及音效。
- 标准数据库文件名、`MapInfos.json` 中引用的地图文件。
- MV `.rpgmvp` / `.rpgmvo` / `.rpgmvm`；MZ `.png_` / `.ogg_` / `.m4a_`。依据 `System.json` 的加密标志转换路径，不修改或解密资源内容。支持 MV 静态 `Decrypter._ignoreList`。
- 音频 `.ogg` / `.m4a`、视频 `.webm` / `.mp4` 作为备选格式；已有的各格式都会对齐，不会要求未部署的备选格式必须存在。

**补充静态发现：** 检查 `index.html`、关联 CSS、入口脚本及启用插件。解析常见 `ImageManager`、`AudioManager`、字体/视频加载调用的字面量，支持静态字符串拼接与转义；读取 `js/plugins.js` 及插件 `@type file` / `file[]` / `struct` 参数。JavaScript 使用语法树解析，不运行脚本。补充线索只在文件存在时参与对齐，未找到的可选脚本引用不会被当作确定缺失。

即使在大小写不敏感的 macOS / Windows 文件系统上，也会通过实际目录项比较大小写，而不是依赖 `exists()` 的结果。

## 修复与数据安全

修复以**引用请求的拼写**为准，只重命名资源文件和必要的目录，不改 JSON、脚本内容、剧情、存档，也不统一强制改为小写。

- 同一资源被要求使用两种不同拼写，或存在仅大小写不同的多个文件/目录：报告冲突，**整次修复不写入**。
- JSON 无法读取、路径越界或引用指向符号链接：报告阻塞，不静默漏过后继续修复。
- 真正缺失的资源单独报告为 `missing`，不下载、不伪造；不阻止其他无歧义的大小写修复。仅剩 missing 时正常退出（`0`）。
- 目录由深到浅改名；通过中间名支持大小写不敏感文件系统上的 case-only rename。
- 目标已存在时不覆盖；普通 I/O 失败会逆序回滚已完成的改名，回滚失败会明确报告。

**修复前关闭游戏并备份目录。** 不支持与游戏、同步程序或另一修复进程并发改动目录；断电、强制终止或硬盘故障不保证自动恢复。

## 可信游戏的自定义数据库解码

```sh
rmgaf ./www --check --trust
rmgaf ./www --trust
```

解码仍需显式授权 `--trust`。游戏代码在子进程内的 `moejs-wasm` 沙箱中执行，不提供 Node.js、文件系统、网络或定时器，仅提供内存中的数据库及加载器所需环境。授权后提示 `warning: trusted game JavaScript execution enabled in moejs-wasm`；`--check` 不会跳过代码执行。

静态扫描发现不可读 JSON 后，从 `js/plugins.js` 中的启用插件提取 `DataManager.loadDataFile` 赋值及其可解析的词法依赖。

可信模式可执行顶层字符串表及解码函数的前置代码，将受支持的计算属性还原后再提取加载器；支持以全局对象为参数的立即调用函数。从入口声明的 `js/libs` 和启用插件中按依赖提取独立库声明（包括 CryptoJS 的 UMD 包装），不执行完整插件启动流程。所有游戏代码执行均在授权后的 worker 中进行。

辅助 JSON（如 DKTools 的 `Stamp.json`）可使用游戏自带的 LZ-String 解压；只有解压结果是 JSON 对象/数组且重新压缩与原文完全一致才接受。明文 JSON 仍优先直接读取，不要求存在自定义加载器。

支持普通函数的局部 `arguments`（包括嵌套箭头函数的词法捕获），以及加载器实际读取的静态属性的单次、无条件字面量初始化（字符串、数字、布尔值或 `null`）。不相关的插件初始化不会执行；依赖条件赋值、重复写入、动态属性或对象别名修改时仍会拒绝提取，而不是忽略这些操作后使用错误数据。

标准数据库和地图使用引擎请求的规范拼写调用加载器，再按不区分大小写的目录索引读取实际文件。因此加密数据库本身的大小写错误也能先解码、再安全改名。

不会启动完整游戏、渲染、事件流程或存档逻辑。加载器依赖条件注册、外部可变状态、浏览器 DOM、未提供的库或动态代码生成时可能不受支持；会报告限制，不猜测算法。不支持的加载器发出警告；仍无法解码的数据库阻止修复。与已成功解码标准数据库逐字节相同的未知备份会单独警告，只扫描标准文件，备份保持不变。

运行限制：输入数据库必须是 UTF-8 文本；输入/输出各最多 64 MiB，子进程总时限 30 秒，单次脚本执行时限为 1–5 秒。V8 堆与 MoeJS guest 内存预算各限制为 768 MiB；这些预算并非整个子进程的总内存硬上限。禁止动态代码生成；字符串表预处理使用独立运行时，用完即关闭。超限、异常或未返回对象会作为解码错误，而不是跳过后声称检查完整。

JS 仅普通注释含无效 UTF-8 时，可在内存中去除该注释后继续扫描；不修改脚本文件。资源字符串、可执行代码和 RPG Maker 插件元数据仍严格检查编码，不猜测原字符或资源名。

## 静态分析边界

“没有发现问题”只针对已识别的静态引用，不等于所有游戏分支均已运行验证：

- 无法穷尽由变量、运行时计算、网络请求或自定义加载器生成的文件名。
- 不猜测插件自定义 JSON 字段、备注标签或未声明类型的裸资源名；不扫描存档及停用插件。静态资源发现跳过第三方 `js/libs`；可信解码仅按需加载其中的独立库。
- 不解析 `.efkefc` 内部二进制纹理依赖；不解释 HTML `<base>` 或任意复杂 CSS 语法。
- MV/MZ 标准资源加密受支持。插件自定义 JSON 加密/压缩可尝试上述可信加载器模式，但不保证覆盖所有插件；默认静态模式遇到不可读 JSON 会阻止修复。
